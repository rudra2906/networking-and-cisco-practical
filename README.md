# 💻 Example Cisco Commands

## Enter Privileged Mode

```bash
enable
```

## Enter Global Configuration Mode

```bash
configure terminal
```

## Configure Interface

```bash
interface fastethernet0/0
ip address 192.168.1.1 255.255.255.0
no shutdown
```

## Configure Enable Password

```bash
enable password cisco
```
